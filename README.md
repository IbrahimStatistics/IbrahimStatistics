### 🔧 Currently building
**[SmartWatch Manager](#)** — a predictive maintenance platform for industrial induction motors, covering the full stack from sensor signal ingestion to fault diagnostics.
- **Ingestion:** async MQTT consumer (`aiomqtt` + `asyncpg`) streaming multi-sensor telemetry (current, vibration, temperature, humidity, energy) into TimescaleDB hypertables
- **Backend:** FastAPI service with JWT-authenticated, time-range-filtered telemetry endpoints
- **Dev strategy:** a virtual edge node replays pre-recorded motor datasets over MQTT, decoupling backend/ML development from physical sensor procurement (IIS3DWB, SCT-013-030, PT100+MAX31865, SHT31, PZEM-004T)
- **Status:** Phase 2 (Ingestion Pipeline) complete, Phase 3 (FastAPI Backend) in progress
